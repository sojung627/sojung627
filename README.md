기업부설연구소에서는 PDF 문서 전처리와 청크 분할, 임베딩 생성, Qdrant 벡터 검색, vLLM 답변 생성을 연결한 RAG 기반 AI 서비스를 구현했습니다.   
검색된 문서가 실제 답변의 근거로 활용되는 전체 파이프라인을 구현하고 검색 정확도를 높이기 위한 청크 구조와 메타데이터를 개선했습니다.  

Java·Spring 및 React 개발 경험을 활용해 AI 기능을 사용자에게 제공하는 서비스를 구현할 수 있습니다.  

모델을 단순히 호출하는 데서 끝내지 않고  
데이터 처리부터 검색과 답변 생성, 안전성 설계, 사용자 인터랙션까지 연결하는 AI 서비스 개발자를 목표로 합니다.
